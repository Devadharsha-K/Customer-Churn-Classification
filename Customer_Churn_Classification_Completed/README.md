# Customer Churn Classification

**AI Engineer Internship Task 1**

This project explores the supplied customer churn dataset, preprocesses numerical and categorical features, compares classification models, evaluates results using cross-validation and a held-out test set, visualizes model performance, and demonstrates predictions for new customers.

## Project files

- `Customer_Churn_Classification.ipynb` - complete notebook.
- `customer_churn_data.csv` - supplied dataset.
- `models_performance_comparison.png` - ROC curves generated by the notebook.
- `requirements.txt` - required Python packages.

## Environment setup

Use Python 3.10 or newer. From this folder, run:

```bash
python -m venv venv
```

Activate the environment on Windows:

```powershell
.\venv\Scripts\activate
```

On macOS/Linux:

```bash
source venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## Run the notebook

```bash
jupyter notebook
```

Open `Customer_Churn_Classification.ipynb` and select **Run All**. Keep the CSV in the same folder as the notebook. The optional interactive prediction function is defined but not launched automatically.

## Important result note

The supplied dataset has 5,880 rows and 21 columns. Initial checks show a nearly balanced target and very similar tenure distributions for churn and non-churn customers. The earlier ROC plot also showed model AUC values around 0.46-0.50. This suggests that the available features may contain little predictive signal. The notebook reports the actual measured results and does not manufacture higher accuracy. Check the dataset's label-generation process and obtain more informative customer-behaviour features before using the model operationally.
